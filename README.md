# Excel HR Dashboard & Survey Reporting

A Business Analytics coursework project at ADA University with two
deliverables in one Excel workbook.

## Q1. HR Dashboard

Built an interactive dashboard with PivotTables, charts, and slicers.
The dashboard summarizes average employee age and salary and compares
average salary across tiers and groups.

## Q2. Employee Survey Report

Used the Excel Data Model and a PivotTable to organize survey results
by employee, supervisor, and survey year. The report summarizes
engagement, satisfaction, eNPS, and performance scores for 2024 and 2025.

## Excel Skills

- PivotTables for grouped reporting
- Dashboard charts and slicers for interactive exploration
- Excel Data Model for survey reporting
